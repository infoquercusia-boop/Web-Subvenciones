SEO on-page: guía completa

SEO · 9 min de lectura · Actualizado enero 2026

El SEO on-page agrupa todas las optimizaciones que puedes aplicar directamente dentro de tu página para mejorar su posicionamiento en buscadores. A diferencia del SEO off-page (enlaces externos, menciones), el on-page está completamente bajo tu control. Esta guía cubre los elementos que más impacto tienen.

1. Título (title tag)

El title tag es el elemento HTML más importante para el SEO on-page. Debe incluir tu keyword principal, mantenerse entre 50 y 60 caracteres y ser único en cada página.

<title>Cómo hacer pan casero: receta fácil paso a paso</title>

Si necesitas ayuda para generar variaciones optimizadas, prueba nuestro Generador de Títulos SEO.

2. Meta description

Aunque no es un factor de ranking directo, la meta description influye en el CTR (click-through rate) desde los resultados de búsqueda. Debe tener entre 155 y 160 caracteres, incluir la keyword principal y una llamada a la acción clara.

<meta name="description" content="Aprende a hacer pan casero con esta receta fácil, paso a paso, con solo 4 ingredientes.">

3. Estructura de encabezados (H1-H6)

Cada página debe tener un único H1 que describa el tema principal. Los H2 dividen las secciones principales y los H3 las subsecciones. Esta jerarquía ayuda tanto a los lectores a escanear el contenido como a los motores de búsqueda a entender su estructura.

  • H1: un solo título por página, con la keyword principal.
  • H2: secciones principales del artículo.
  • H3: subdivisiones dentro de cada sección.

4. Densidad y uso natural de keywords

Olvida la vieja regla de "densidad de keyword del 2%". Google usa procesamiento de lenguaje natural para entender el contexto semántico. En su lugar, enfócate en cubrir el tema en profundidad, usando variaciones naturales y palabras relacionadas.

5. URLs limpias y descriptivas

Una URL corta y legible mejora tanto el SEO como la experiencia de usuario:

✅ /blog/como-hacer-pan-casero
❌ /blog/post?id=48291&cat=3

6. Enlazado interno

Enlazar entre tus propias páginas ayuda a distribuir la "autoridad" SEO y facilita que Google rastree todo tu sitio. Cada artículo de blog debería enlazar a páginas relevantes: herramientas relacionadas, guías complementarias, o artículos previos sobre el mismo tema.

7. Optimización de imágenes

Las imágenes deben tener:

  • Texto alternativo (alt) descriptivo para accesibilidad y SEO.
  • Nombres de archivo descriptivos (pan-casero-horneado.jpg en vez de IMG_2931.jpg).
  • Formato optimizado (WebP cuando sea posible) para mejorar la velocidad de carga.

8. Velocidad de carga (Core Web Vitals)

Google usa métricas de experiencia real como el Largest Contentful Paint (LCP), Interaction to Next Paint (INP) y Cumulative Layout Shift (CLS) como señales de ranking. Un sitio estático sin frameworks pesados, como el que puedes construir con HTML y CSS puro, tiende a obtener mejores resultados que aplicaciones cargadas de JavaScript innecesario.

9. Datos estructurados (Schema.org)

El marcado Schema.org ayuda a Google a mostrar resultados enriquecidos (rich snippets): estrellas de valoración, tiempo de preparación, preguntas frecuentes, etc. Para artículos de blog, el tipo más común es BlogPosting; para herramientas web, WebApplication.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "Título del artículo",
  "datePublished": "2026-01-20"
}
</script>

10. Longitud y calidad del contenido

No existe una longitud "mágica", pero el contenido debe ser lo suficientemente completo para responder la intención de búsqueda del usuario. Usa nuestra Calculadora de Tiempo de Lectura para comprobar si tu artículo tiene una extensión adecuada: menos de 300 palabras suele ser insuficiente, más de 3000 puede beneficiarse de dividirse en secciones o en varios artículos.

Checklist de SEO on-page

  • Title único, 50-60 caracteres, con keyword principal
  • Meta description única, 155-160 caracteres
  • Un solo H1, jerarquía de H2/H3 clara
  • URL corta y descriptiva
  • Enlaces internos relevantes
  • Imágenes con alt text y nombres descriptivos
  • Datos estructurados Schema.org
  • Contenido completo y bien estructurado

El SEO on-page no es una tarea única: es un proceso continuo de revisión y mejora. Aplica estos principios en cada nuevo artículo y revisa periódicamente tu contenido antiguo para mantenerlo optimizado.
