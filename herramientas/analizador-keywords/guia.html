Guía: cómo interpretar el Analizador de Keywords

Guía de la herramienta · 3 min de lectura

1. Volumen de búsqueda estimado

Es el número aproximado de búsquedas mensuales para esa palabra clave. Usamos un dataset con volúmenes de referencia para keywords populares; para el resto, generamos una estimación orientativa. No sustituye a herramientas profesionales como Google Keyword Planner, pero sirve para comparar ideas rápidamente.

2. Intención de búsqueda

  • Informacional: el usuario busca aprender algo (ej. "cómo hacer pan casero").
  • Transaccional: el usuario quiere comprar o contratar (ej. "comprar bicicleta eléctrica").
  • Navegacional: el usuario busca una marca o sitio concreto (ej. "iniciar sesión gmail").

Escribe contenido alineado con la intención: un artículo informativo para keywords informacionales, una página de producto para transaccionales.

3. Dificultad estimada

Indica cuánta competencia tiene esa keyword en los resultados de búsqueda: baja significa que es más fácil posicionar, alta indica mucha competencia de sitios establecidos.

4. Keywords relacionadas

Úsalas como subtítulos (H2/H3) dentro de tu artículo para cubrir el tema en profundidad y capturar búsquedas relacionadas (SEO semántico).

5. Historial de búsquedas

Tus últimas 15 búsquedas se guardan localmente en tu navegador para que puedas volver a consultarlas sin escribirlas de nuevo.
